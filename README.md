# 🚗 Car Price Prediction App

A Machine Learning web application built with **Streamlit** that predicts the selling price of a used car using a trained **Linear Regression** model.

## 📌 Features

- Predict selling price of used cars
- Simple and interactive Streamlit interface
- Data visualization with Plotly
- Dataset preview and statistics
- Fast and accurate predictions using a pre-trained model

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- Scikit-learn
- Plotly
- Joblib

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/harshpatel1315/Car-Price-Predictor.git
```

### 2. Go to the project folder

```bash
cd Car-Price-Predictor
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```
